WordPress Integration Instructions

1. Include the JavaScript file in your WordPress admin pages:

<script src="http://localhost:3500/api/assets/export-utils.js"></script>

2. For single ad export buttons, use these HTML attributes:

<button class="button button-small adi-export-single" 
        data-ad-id="" 
        data-ad-name="" 
        title="Export this ad's data">
    <span class="dashicons dashicons-download"></span>
    Export
</button>

3. For "Export All" buttons, use this class:

<button class="button adi-export-all">
    <span class="dashicons dashicons-download"></span>
    Export to Excel
</button>

4. Add these optional elements for user feedback:

<div class="adi-loading" style="display: none;">Downloading...</div>
<div class="adi-export-success" style="display: none;"></div>
<div class="adi-export-error" style="display: none;"></div>

5. API Endpoints Available:

  • GET /api/ads/export/excel?ad_id=123 - Export single ad
  • GET /api/ads/export/excel - Export all ads
  • GET /api/ads/export/excel?start_date=2024-01-01&end_date=2024-01-31 - Export with filters
